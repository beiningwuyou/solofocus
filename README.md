## 💡 为什么做 SoloFocus？

市面上绝大多数 To-Do / 待办清单软件，本质上都只是**“被动的记录本”**：
1. **记了一堆任务，每天依然不知道该干嘛**：待办清单无限膨胀，每天早晨面对几十条任务陷入“决策瘫痪”与无休止的拖延焦虑。
2. **大任务缺乏拆解，难以下手**：任务往往只是一句模糊的话（如“完成季度报告”、“重构支付模块”），缺乏具体的执行流程与逻辑梳理，开工阻力极大。
3. **做完就扔，经验无法沉淀**：辛辛苦苦摸索出一套流程，任务一勾选就烟消云散；下次做类似事情，又得重新走一遍弯路，无法形成经验复利。

### 核心思考：在 To-Do 软件中，Agent 的真正协同价值是什么？

SoloFocus 并不是简单地给待办软件旁边塞一个“聊天对话框”，而是**让 Agent 深度融入任务从规划、拆解到复盘的全生命周期**：

```text
 ┌─────────────────────────────────────────────────────────────┐
 │                     Agent × 人机协同闭环                     │
 └─────────────────────────────────────────────────────────────┘
          │                                           ▲
   [ 1. 智能推荐 ]                             [ 3. 记忆沉淀 ]
   每天主动推算分析                             做过的事/跑过的流程
   推荐「今天最该干什么」                       沉淀为可复用的资产/SOP
          │                                           │
          ▼                                           │
   [ 2. 流程拆解 ] ───────► [ 用户执行交付 ] ─────────┘
   梳理任务逻辑与依赖
   拆成落地步骤与清单
```

* 🎯 **1. 智能推荐：告诉你「今天该干什么」**  
  每天清晨，Agent 结合你当前的活跃项目、截止日期、逾期风险与个人精力基准，主动为你智能推荐今日最该推进的高优事项，过滤次要杂音，帮你快速进入心流。
* 🧩 **2. 流程拆解：帮你理清「任务流程与执行逻辑」**  
  面对复杂模糊的目标，Agent 协助梳理前后依赖，拆解出具体、可执行的操作步骤（Step-by-step）与检查清单（Checklist），把大石头切碎，大幅降低启动阻力。
* 💎 **3. 记忆沉淀：让做过的事成为「可复用的资产」**  
  完成一件事情不是终点。经过的流程、验证过的步骤，Agent 能帮你提炼沉淀为结构化 SOP（标准作业程序）与记忆资产；下次遇到类似任务或新项目时，直接借力复用，让每次交付都成为个人能力的持续复利。

## ✨ 核心特性

- 🤖 **Agent 深度协同**：
  - **每日智能排期（Agent Pulse）**：晨间智能简报，推荐今日攻坚核心，辅助次优任务科学顺延。
  - **任务工序拆解**：针对复杂任务生成结构化步骤与防错核对清单。
  - **SOP 资产提炼与复用**：从已交付项目中一键提炼经验模版，在新项目中自动推荐匹配。
- 🖥️ **今日专注大盘**：聚合今日核心事项、微习惯打卡、番茄专注时钟与当前工序抽屉，单屏直达。
- ⚡️ **双轨数据架构**：
  - **SQLite (WAL 模式)**：毫秒级极速渲染、关系索引与本地快速检索。
  - **Obsidian 兼容 Markdown Vault**：作为终极真实数据源（Single Source of Truth），所有任务和笔记均为纯文本 Markdown，零数据绑定。
- 📥 **灵感与信息收集箱**：支持快速捕获碎片灵感，支持本地邮件（IMAP）智能同步，经人机确认后分发至项目与任务。
- 🛡️ **100% 离线与隐私优先**：
  - 纯本地运行，不设任何云端依赖和外部账号；
  - 你的数据、任务、日志全部留在你的电脑本地。
- 🤝 **人机协同确认（Human-in-the-Loop）**：
  - Agent 负责出谋划策（推荐、拆解、提炼），但所有写入、排期与调整均需由你确认后生效，不擅自越权。

## 📂 项目结构

- `src/client/`：界面层（React 19、Tailwind、CodeMirror、Design Tokens）。
- `src/server/`：服务层（Fastify、Agent 协同引擎、SQLite 状态同步、Vault 文件操作）。
- `src/shared/`：领域模型与数据契约定义。
- `src-tauri/`：macOS 桌面壳、系统托盘与原生打包配置。

- `data/samples/`：开箱即用的脱敏样例 Vault。
- `docs/`：项目规范、打包指南与系统设计说明。
- `scripts/`：统一的本地开发、测试、构建与安装入口。

## 🚀 快速开始

### 依赖环境
* Node.js >= 22.0.0
* pnpm >= 9.0.0
* Rust & Cargo（若需要编译 Tauri 桌面端）

### 1. 本地运行 (开发模式)

```bash
# 安装依赖
pnpm install

# 使用内置样例库启动（与个人实际数据物理隔离）
export WORKBENCH_VAULT_PATH="$(pwd)/data/samples/vault"
./scripts/dev.sh
```
应用将自动启动并在浏览器打开：`http://127.0.0.1:5173`（API 服务监听在 `4317` 端口）。

### 2. 自动化测试与构建

```bash
# 运行自动化测试与设计系统校验
./scripts/test.sh

# 构建前端与服务端产物
pnpm build

# 构建 macOS 桌面安装包
./scripts/build.sh
```

### 3. 安装到本机 Applications

```bash
./scripts/install-local.sh
```
该脚本将构建并更新 `/Applications/个人工作台.app`，并将正式 Vault 路径配置记录在系统 `Application Support` 中，实现 App、源码与用户个人数据的彻底分离。

## 🔐 隐私与数据安全

- **零数据上报**：绝无任何遥测（Telemetry）、网络埋点或第三方追踪服务。
- **数据完全自主**：所有待办、任务与笔记均保存在本地文件夹中，即使未来不使用本软件，仍可用 Obsidian 或任意文本编辑器无缝查看和编辑。
- **本地凭据安全**：敏感配置（如邮件 IMAP 授权码）均妥善保存在本地 Application Support 中，绝不会被 Git 提交或泄漏。
